# Gestión del avance y riesgos

## Estado del tablero (GitHub Projects)

| Columna | Tareas |
|---------|--------|
| Finalizado | Levantamiento de requisitos; Modelos UML; Definición de arquitectura; README y documentación |
| En revisión | Nota técnica de versión |
| En progreso | Definición de endpoints de la API |
| Por hacer | Módulo de ventas; Autenticación y roles |
| Backlog | Alertas de stock mínimo; Reportes avanzados |

## Riesgos

| Riesgo | Probabilidad | Impacto | Acción de respuesta |
|--------|--------------|---------|---------------------|
| Pérdida de datos del inventario | Media | Alto | Plan de respaldo periódico de la base de datos |
| Cambios en los requisitos durante el desarrollo | Alta | Medio | Control de cambios mediante Issues |
| Resistencia del personal al nuevo sistema | Media | Medio | Capacitación básica y interfaz sencilla |
| Retrasos por falta de tiempo del equipo | Media | Medio | Priorizar tareas en el tablero |
