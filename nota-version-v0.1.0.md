# Nota técnica de versión v0.1.0

**Fecha:** octubre de 2026
**Sistema:** Gestión de Inventario y Ventas para Colmado

## Contenido de la versión
Esta versión inicial reúne la documentación técnica del sistema: requisitos funcionales y no funcionales con criterios de aceptación, modelos UML, definición de la arquitectura, tablero de gestión del avance y README actualizado.

## Cambios controlados
Se incorporaron criterios de aceptación medibles a los requisitos, se completaron los modelos UML, se definió la separación entre frontend y backend, y se organizaron las incidencias y riesgos mediante Issues y GitHub Projects.

## Aspectos pendientes
Implementación de los módulos de inventario y ventas, autenticación por roles, pruebas funcionales y plan de respaldo de datos.

## Próximo paso técnico
Diseñar y documentar los endpoints de la API REST y construir el módulo de inventario como primer incremento funcional.
